# Recycler Dark Alchemy Switcheroo
Swaps Recycler and Dark Alchemy's functionality with each other.

Also includes a config option to disable *recyclying* hexes.

|                                                                      | Pickup               | Description                                                                                                    |
|----------------------------------------------------------------------|----------------------|----------------------------------------------------------------------------------------------------------------|
| ![Recycler](https://riskofrain2.wiki.gg/images/Recycler.png)         | Recycle items.     | **Recycles** a targeted Item into two Items of a **lesser tier**.                                              |
| ![Dark Alchemy](https://riskofrain2.wiki.gg/images/Dark_Alchemy.png) | Equivalent exchange. | **Transmute**  an Item or Equipment into a different one. *Can only be converted into the same tier one time.* |
